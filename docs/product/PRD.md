# 球脉（FootPulse AI）产品需求文档

- 状态：Draft v0.1
- 日期：2026-06-28
- 负责人：Product
- 目标发布：世界杯淘汰赛期间的可用 MVP

## 1. 一句话产品

球脉是一款面向中文足球用户的 AI 情报产品：每天把分散、重复、真假难辨的足球消息整理成可追溯的简报，并用经过回测和校准的模型解释比赛概率。

## 2. 用户问题

用户不是缺足球消息，而是缺少：

- 低噪声：同一条消息被数十个账号重复转述。
- 可判断：传闻、接触、报价、达成协议和官宣混在一起。
- 可追溯：AI 摘要经常丢失原始出处和时间。
- 可解释：预测只给一个比分，没有概率、版本与历史表现。
- 中国时区友好：赛程、日报和提醒未按北京时间组织。

## 3. 目标用户与任务

### 3.1 核心用户

1. 每天花 10 分钟了解足坛动态的中文球迷。
2. 需要快速选题和核验来源的足球内容创作者。
3. 喜欢赛前分析、但不满足于“拍脑袋预测”的数据型球迷。

### 3.2 用户任务

- “早上让我在 5 分钟内知道过去 24 小时真正重要的转会进展。”
- “开赛前让我看懂双方状态、关键缺阵和概率变化。”
- “每天用一篇中文文章回顾世界杯，并知道今天值得看什么。”

## 4. 产品范围

### 4.1 P0：世界杯期间必须上线

- 世界杯日报：昨日赛果、关键事件、晋级形势、今日赛程、关注点。
- 赛前预测：90 分钟胜/平/负、期望进球、常见比分、晋级概率。
- 每条事实可展开查看来源、发布时间和核验状态。
- 运营后台可审稿、修改、退回和发布。

### 4.2 P1：世界杯期间补齐

- 每日转会简报。
- 关注球队、球员与订阅提醒。
- 预测变化曲线与模型历史成绩页。
- 文章自动分发到站内与允许的外部渠道。

### 4.3 暂不做

- 不做实时文字直播；数据延迟与版权成本不适合 MVP。
- 不提供投注建议、赔率比较或“稳胆”。
- 不允许无人审核地发布低置信度伤病、纪律或私人信息。
- 不在 MVP 阶段拆成大量微服务或放任智能体无限循环。

## 5. 信息架构

```text
首页
├── 今日焦点
├── 世界杯日报
├── 今日比赛与预测
└── 转会速览

世界杯
├── 日报归档
├── 赛程/赛果
├── 比赛详情与预测
└── 模型表现

转会
├── 每日简报
├── 按球队/球员筛选
└── 消息时间线

个人
├── 关注与提醒
└── 内容偏好
```

## 6. 核心体验

### 6.1 每日转会消息

系统将文章拆成“主张（claim）”，围绕球员、来源俱乐部、目标俱乐部、动作、金额、阶段和时间建立事件簇，而不是简单拼接标题。

阶段统一为：

`传闻 → 关注/接触 → 谈判 → 报价 → 达成协议 → 体检/签约 → 官宣`

同时允许 `停滞`、`告吹`、`辟谣`。每个卡片展示：

- 一句话进展与“相比昨日发生了什么”。
- 当前阶段、置信等级、首次/最近更新时间。
- 支持来源与冲突来源。
- AI 整理标识，不展示伪造引语。

发布门槛：

- A（确认）：官方来源，或权威来源且有独立佐证。
- B（可信进展）：至少两个独立可靠来源，关键信息一致。
- C（单一消息）：可以进入“传闻观察”，不可写成确定事实。
- D（噪声/冲突）：不进日报正文，仅留审计记录。

### 6.2 世界杯日报

固定结构让用户形成习惯：

1. 30 秒摘要。
2. 昨日赛果与关键转折。
3. 晋级/对阵变化。
4. 伤停与球队消息（标注来源和时间）。
5. 今日北京时间赛程与三场看点。
6. 模型观点：只引用已发布的结构化预测。
7. 更正记录与完整来源。

日报中的赛果、赛程、排名必须来自结构化赛事数据源，生成模型不得自行计算或凭记忆补全。

### 6.3 比赛预测

默认展示：

- 90 分钟主胜/平/客胜概率，三者之和为 100%。
- 双方期望进球与最可能的 3 个比分。
- 淘汰赛的晋级概率，明确区分常规时间、加时和点球。
- 关键因素、数据截止时间、模型版本。
- “模型有多可靠”：滚动窗口 Brier Score、Log Loss 和校准图。

不展示单一“必然比分”；概率发生明显变化时说明变化来自阵容、伤停、数据更新还是模型升级。

## 7. 功能需求与验收

| ID | 需求 | MVP 验收标准 |
|---|---|---|
| NEWS-01 | 多源采集 | 支持 API、RSS 和许可网页适配器；原始记录不可覆盖 |
| NEWS-02 | 去重聚类 | 同一主张跨来源合并，保留所有出处 |
| NEWS-03 | 证据核验 | 每个事实句至少关联一个证据片段和 URL |
| NEWS-04 | 内容生成 | 模板化初稿；无证据字段保持空缺而非补写 |
| NEWS-05 | 编辑发布 | 支持预览、修改、批准、退回、定时和更正 |
| WC-01 | 世界杯日报 | 每日北京时间 08:00 前生成候选稿，发布前人工确认 |
| PRED-01 | 赛前预测 | 开赛前 24h/6h/1h 可重算并保留版本 |
| PRED-02 | 可解释性 | 展示关键输入、数据截止和模型卡 |
| PRED-03 | 模型治理 | 只有通过离线门槛并经批准的模型可进入生产 |
| TRUST-01 | 来源透明 | 用户能从事实或预测跳转到来源/数据说明 |
| OPS-01 | 可观测性 | 每次运行可查看步骤、输入版本、输出、耗时和失败原因 |
| OPS-02 | 可降级 | LLM 不可用时仍可发布结构化赛程/赛果页 |

## 8. 信任与安全

- 内容层明确区分“事实、来源观点、模型推断、编辑观点”。
- 对伤病、纪律、合同金额等易变信息显示“截至时间”。
- 所有自动发布开关默认关闭；P0/P1 内容均有人审。
- 更正不静默覆盖，保留版本和更正说明。
- 页面显示数据/新闻来源归属，遵循抓取许可、robots 与供应商协议。
- 预测不面向未成年人营销，不与博彩转化绑定。

## 9. 成功指标

### 北极星指标

每周完成至少 3 次“有效阅读”的用户数；有效阅读定义为阅读日报/转会简报超过 45 秒，或展开至少一个来源/预测解释。

### 质量护栏

- 已发布事实的来源覆盖率：100%。
- 经确认的事实性错误率：< 1%，严重错误为 0。
- 重复消息压缩率：> 70%。
- 世界杯日报人工审稿中位耗时：< 10 分钟。
- 预测：相对“按世界排名/固定主场优势”的基线，在时间外测试集上 Log Loss 改善 ≥ 5%。
- 概率校准：主要概率桶的预测值与实际值偏差 ≤ 5 个百分点。

点击率、阅读时长不能压过事实准确率和校准度。

## 10. 关键产品决策

1. MVP 是编辑增强产品，不是全自动媒体。
2. 同一底座运行内容闭环和预测闭环，但模型、质量门槛和发布策略分开。
3. 用户看到的是证据与概率；Harness/Loop 是后台可靠性能力，不作为营销噱头。
4. 先做响应式 Web 和运营后台；数据与留存验证后再决定原生 App。
