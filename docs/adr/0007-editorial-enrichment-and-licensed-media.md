# ADR 0007：分层编辑增强与许可媒体资产

- 状态：Accepted
- 日期：2026-07-01

## 背景

事实正确的摘要仍可能像数据库播报。用户希望转会报告解释球员与关联球队，比赛报告呈现进球者和时间线，并加入相关图片或精彩视频。

## 决策

1. 将内容生产拆为事实层、编辑层和媒体层。模型可以组织表达，但不能把编辑判断写成俱乐部动机或补造球员数据、进球分钟。
2. 报告新增 `player_spotlights` 与 `match_timeline`。球员指标必须在引用资料中出现；带分钟的事件必须能在引用证据中定位。
3. Sportmonks 作为需订阅的结构化增强 MCP，提供球员档案/统计与比赛 events、timeline、lineups、scores；没有 Token 时相关字段留空。
4. 图片仅从 Source Registry 批准的媒体接口进入。Wikimedia Commons 必须通过许可证白名单并保存作者、许可和文件页；未经视觉核验的画面标记为“相关性待人工确认”。
5. 视频只使用 YouTube Data API 在人工批准的官方频道白名单中查找 `videoEmbeddable=true`、`videoSyndicated=true` 的链接；不下载、转码或重新托管视频。
6. 模型输出的 `media_assets` 一律拒绝；只有 Harness 版权连接器可在校验后注入媒体资产。
7. 若需要自动判断图片是否确为目标球员或对应比赛，另接视觉模型；视觉结论只影响相关性标签，不改变版权状态和足球事实。

## 后果

报告可以更像足球编辑作品，同时保持数据与版权边界。完整球员数据、逐分钟事件和官方视频需要 Sportmonks Token、YouTube API Key 及官方频道 ID；缺少配置时功能安全降级，不抓取任意网页图片或盗链视频。

## 验证

- 外部预测别名规范化和淘汰赛晋级概率兜底不再导致整单失败。
- 无证据的球员数字或比赛分钟被质量门拒绝。
- Commons 非许可图片不进入报告，许可图片保留署名。
- YouTube 查询只能使用配置的频道白名单并要求可嵌入。
- 模型直接生成媒体 URL 时质量门拒绝。
