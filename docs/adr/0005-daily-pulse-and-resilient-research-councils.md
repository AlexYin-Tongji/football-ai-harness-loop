# ADR 0005：统一《今日球脉》与可降级研究委员会

- 状态：Accepted
- 日期：2026-07-01

## 背景

用户希望日报与转会信息合并为一个消费者产品，同时要求扩大传闻覆盖、增加模型研究深度，并解决比赛预测因单个模型席位失败而整单中止的问题。

## 决策

1. 公共产品将赛事日报与转会日报合并为《今日球脉》；旧 API 类型保留兼容，内部领域边界不合并。
2. 统一日报使用两个并行 Flash 研究桌：赛事新闻桌与转会市场桌。两个 Pro 主笔分别成稿，最后由 Pro 总编辑去重和整合；最多一次校验修订，总模型轮次不超过 7。
3. 新闻层同时使用批准的出版方 RSS 与 GDELT 发现层。GDELT 只接收 Publisher Registry 中批准的域名，结果标记为 `unverified_lead`，不得自动升级成事实。
4. 传闻允许进入“传闻雷达”，但引用发现层线索的段落必须显式出现“传闻、据报道、未核实、线索或尚未确认”等标签。
5. 比赛预测的两个 Flash 席位允许独立失败。瞬时上游错误有限重试；仍失败时由 Pro 根据原始证据保守终审并在报告中披露委员会降级，避免单席故障造成整单失败。
6. 预测输出新增外部观点对照；只有证据明确包含外部判断或概率时才能展示，禁止模型补造。

## 后果

统一入口降低用户选择成本，同时保留不同任务的上下文隔离。深度日报会增加延迟和成本，因此必须显示真实进度并保留预算上限。发现层显著提高线索召回率，但不等于事实核验；商业生产仍需授权新闻检索与结构化赛事数据。

## 验证

- 注入一个预测席位 5xx，报告仍能降级完成。
- 未核实线索进入无传闻标签段落时，质量门必须拒绝。
- 日报正常路径记录 2 个研究席位、2 个分栏主笔和 1 个总编辑调用。
- 外部预测引用不存在的 evidence ID 时必须拒绝。
