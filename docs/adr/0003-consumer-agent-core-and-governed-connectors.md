# ADR 0003：2C 产品、预测委员会与受治理连接器

- 状态：Accepted
- 日期：2026-06-29

## 决策

1. 公共网页只呈现用户任务、报告和来源，不呈现模型、Harness、轮次或调试信息。
2. 外部数据只能通过 Source Registry 批准的 MCP 连接器进入 Harness；连接器默认只读、后端持有凭据。
3. GDELT/NewsAPI 属于发现层，不自动成为事实证据；世界杯结构化事实首期使用 football-data.org，FIFA 官方页面用于核验，Sportmonks 作为生产深度数据候选。
4. 预测采用两个相互独立的 Flash 分析席位与一个 Pro 终审席；概率、引用和截止时点由确定性代码校验。
5. LLM 对话只作为单次运行上下文。跨运行记忆保存为结构化业务对象，不保存隐藏思维链。
6. 后台默认关闭，开启后必须使用独立管理令牌；报告、更正、赛果和模型配置写入继续要求领域权限。

## 取舍

多席位预测增加两次低成本调用，但能显式暴露分歧；MCP 增加一层工程边界，但把密钥、授权、超时和数据裁剪从提示词移到可测试代码。NewsAPI 免费计划不能用于生产，因此不作为默认运行依赖。
