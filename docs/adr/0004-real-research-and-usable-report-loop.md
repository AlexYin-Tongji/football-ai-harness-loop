# ADR 0004：真实检索优先与可用报告闭环

- 状态：Accepted
- 日期：2026-06-30

## 背景

V3 公共页面已经具备消费产品外观，但浏览器仍提交本地演示证据。这会让用户误以为报告来自实时资料，也使来源按钮、编辑和失败恢复无法接受真实检验。

## 决策

1. 公共页面只调用 `/v1/research/reports`：后端先检索批准来源，再构建 `ReportRequest`，浏览器不得生成证据。
2. 增加 Guardian Football RSS 作为开发/非商业阶段的真实发现源，只保存标题、URL、时间和短摘录；不保存 feed 全文。
3. 外部 feed 最多重试一次，缓存 15 分钟；连接失败可使用不超过 6 小时的进程内缓存，否则明确失败，不降级为假数据。
4. 日报和转会报告使用 V4 Flash 且关闭思考模式；比赛预测使用两个并行 Flash 分析席和一个 Pro 终审席。
5. 预测席位 schema 失败最多修复一次，所有分析席与终审总模型调用不得超过 5 次。
6. 增加简体中文、引用 ID、概率归一化和来源截止时间质量门。
7. 报告向用户显示可点击来源，并允许在浏览器内编辑、复制和保存 Markdown；编辑内容不自动写回服务器。

## 后果

本地 Beta 已能用真实来源和 DeepSeek 生成报告。Guardian RSS 的使用边界不支持直接宣布商业生产就绪；对外商业发布前仍需购买或签署可商用数据协议，并增加至少一个独立来源及 football-data/Sportmonks 比赛事实。
