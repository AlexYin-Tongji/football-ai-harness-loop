# 世界杯比赛预测模型设计

## 1. 产品输出

模型分别回答两个问题，禁止混为一个概率：

1. **90 分钟赛果**：主胜 / 平 / 客胜，以及比分分布。
2. **淘汰赛晋级**：将加时赛与点球阶段显式建模后的晋级概率。

每个预测绑定 `match_id + feature_snapshot_id + model_version + cutoff_at`，赛前更新不覆盖旧版本。

## 2. MVP 模型栈

### M0：透明基线

- FIFA 排名或等价强度差。
- 固定/估计的主场与洲际因素。
- 多项逻辑回归输出胜/平/负。

### M1：Elo + 时间衰减 Poisson

- 使用国家队比赛构建时间衰减 Elo。
- 进球数采用 Poisson；低比分相关性使用 Dixon-Coles 修正。
- 攻防强度、赛事重要性、中立场、休息天数纳入模型。
- 通过蒙特卡洛或解析比分矩阵得到 W/D/L 与比分概率。

### M2：校准集成（达到门槛后）

将 M0/M1 与基于结构化特征的梯度提升模型集成，再用验证集做 isotonic 或 Platt calibration。xG、阵容价值、伤停和球员级特征只有在许可、覆盖率和时间一致性满足要求后加入。

LLM 不参与概率计算。

## 3. 数据与特征

### 3.1 必需数据

- 历史国家队比赛：开球时间、地点、赛制、赛果。
- 官方/授权赛事赛程与实际比赛状态。
- 每个时间点可获得的球队强度信息。

### 3.2 候选特征

| 组 | 特征示例 |
|---|---|
| 长期实力 | Elo、FIFA 积分、近 2 年对手调整净胜球 |
| 近期状态 | 近 5/10 场时间衰减表现、xG 差（若许可） |
| 赛事情境 | 中立场、淘汰赛、东道主、休息天数、旅行距离 |
| 阵容 | 首发稳定度、关键球员可用性、门将/前锋影响 |
| 对阵风格 | 控球/压迫/转换等结构化指标，覆盖不足时禁用 |

不使用赛后才知道的信息。任何伤停或首发特征必须保存“当时可见”的时间戳，防止回测穿越。

## 4. 淘汰赛处理

- 先估计 90 分钟比分分布。
- 对 90 分钟平局的路径单独模拟 30 分钟加时，缩放进球强度并允许疲劳因素。
- 若仍平局，使用保守的点球先验；只有样本和球员信息充分时才偏离 50/50。
- 页面同时展示“90 分钟赛果”和“晋级”，避免用户误读。

## 5. 训练与回测

- 按时间滚动切分，不随机打乱比赛。
- 超参数只能看训练/验证窗口；最终世界杯窗口完全留出。
- 同一赛事后续比赛不能泄漏到早期比赛特征。
- 与至少三个基线比较：均匀概率、排名基线、市场共识（若合法获得且只用于评估）。

核心指标：

- Log Loss：惩罚自信且错误的预测。
- Brier Score：衡量概率误差。
- Ranked Probability Score：利用胜/平/负的有序关系。
- Calibration Error 与可靠性图。
- 分组表现：强弱差、淘汰赛、东道主、数据完整度。

“猜中率”只作为辅助指标，不作为晋级生产的主要标准。

## 6. 生产晋级门槛

候选模型必须同时满足：

1. 时间外测试集 Log Loss 相对 M0 改善至少 5%。
2. Brier Score 不退化，主要概率桶误差不超过 5 个百分点。
3. 关键分组无明显灾难性退化。
4. 特征可在预测截止点稳定取得，缺失时有已验证的回退。
5. 模型卡、代码提交、训练数据窗口和制品哈希完整。
6. 人工批准后先影子运行，再切换生产别名。

若新模型失败，生产别名保持不变。模型切换与预测内容发布是两个独立审批。

## 7. 线上更新节奏

- T-24h：常规赛前版。
- T-6h：伤停与最新球队消息更新。
- T-75min：官方首发可用时生成最终版。
- 开赛后：冻结赛前预测；MVP 不伪装成实时预测。

赛后自动写入结果并计算指标，指标在结果完整性确认后更新。小样本波动显示置信区间，不因一天结果自动改模型。

## 8. 用户解释模板

```text
截至 2026-06-28 12:00（北京时间），模型 v0.1 给出：
90 分钟 A 胜 46%、平 29%、B 胜 25%；A 队期望进球 1.42，B 队 0.96。
淘汰赛晋级概率：A 61%、B 39%。
主要影响：长期实力、近期对手调整表现、休息时间。
这是概率估计，不是确定赛果；首发公布后可能更新。
```

模型解释只能引用实际进入该版本的特征，不能让 LLM 编造“关键因素”。

## 9. 数据限制

StatsBomb Open Data 可用于原型研究和历史世界杯事件数据，但覆盖与许可不等同于 2026 实时生产数据。生产应采购或接入明确覆盖 2026 世界杯、允许产品展示与模型使用的数据服务，并在合同中确认衍生概率的使用权。
