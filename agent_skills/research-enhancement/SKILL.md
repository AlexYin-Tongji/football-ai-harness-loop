# 资料增强层

## 目标

增强层只服务于“第二层资料精简”之后的明确缺口。它不重新写稿，不扩大事实结论，只提出并执行必要的补采需求。

## 可以提出的需求

- `player_profile`：精简资料里出现高优先级球员，且报道需要说明位置、国籍、当前球队或基础资料。
- `club_context`：转会或比赛叙事需要俱乐部背景，但只有在已有授权球队资料接口时才执行；否则降级为人工补充。
- `licensed_image`：人物卡需要图片时，只查 Wikimedia Commons 许可过滤结果；Sportmonks 图片是否可展示取决于合同，不自动使用。
- `official_video`：只查 YouTube 官方频道白名单内可嵌入视频，只保存外链、标题、缩略图和频道名。它可以承担两类视觉位：赛事结束后的 `report_cover` 首图，以及进球、点球、VAR、绝杀等关键事件下方的 `timeline` 画面。
- `match_context`：比赛预测或日报需要结构化赛果、阵容、事件、比分变化；由 football-data 或 Sportmonks 只读工具提供。
- `gif`：当前没有批准的 GIF/比赛动图来源；只能写入人工补充提示，不得自动抓取新闻图、社媒动图或比赛片段。

## 去哪里补什么

- 曼联、皇马、巴萨等俱乐部相关消息：先找俱乐部官网、所在联赛官网、足协/赛事官网，再用 BBC、Guardian、Sky、ESPN、Marca、AS、Diario Sport、Mundo Deportivo 等已登记发布者补报道脉络。
- 球员资料：先用 Sportmonks 等授权结构化接口；没有 key 或合同不覆盖时，只从已有证据摘取位置、球队和赛季数据，不用模型记忆补身价、年龄或数据。
- 转会事件：围绕“球员 + 当前俱乐部 + 目标俱乐部 + 状态词”补独立来源；官方公告、报价、原则协议、体检、否认必须分层。
- 比赛事件：赛果、进球者、分钟、比分变化优先来自 football-data/Sportmonks 或赛事官方比赛中心；新闻报道只能辅助叙事。
- 关键图：人物图优先 Commons 许可图片；比赛画面优先官方比赛中心或官方频道视频外链。遇到比赛报道时，优先为“赛事首图”生成官方高光查询；遇到明确进球、点球、VAR 或绝杀时，再为该事件生成更具体的官方视频查询。GIF/短视频片段没有批准自动源时，输出清晰的人工补图提示，例如“补官方高光第 72 分钟进球画面”，不要自动抓取。

## 选择规则

- 每条需求必须绑定已有 `evidence_ids`，说明为什么需要补采。
- 优先级 1 表示会影响事实准确性；优先级 5 表示可选呈现素材。
- 没有授权来源、没有 key、套餐不覆盖或返回为空时，返回 warning，不用未登记来源替代。
- 不为了装饰找图片；只有人物卡、官方视频或报道可读性确实受益时才请求媒体。
- 不让媒体结论改变足球事实。图片匹配只能说明“元数据匹配/待人工确认”，不能证明转会或出场事实。
- 官方视频相关性必须来自球队、球员、赛事或事件词匹配；比分、年份、号码不能单独触发命中。

## 输出边界

- 增强层输出需求清单或规范化补充证据，不写正文。
- 不保存完整新闻正文、付费原始数据、图片文件、视频文件或隐藏推理。
- 对合同相关数据使用“结构化字段摘要”，并在 warning 中保留再分发限制。
