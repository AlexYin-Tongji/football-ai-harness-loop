# ADR 0021：缺口驱动搜索与读者安全兜底

- 状态：Accepted
- 日期：2026-07-06

## 背景

Facts-first 解决了“当天比赛清单和比分不全”的问题，但 2026-07-04
日报测试暴露了两个新的产品问题：

1. 转会、教练、人物和场外信息仍受早期证据预算限制，容易被 URL 收集、
   Leader 分栏或栏目小组裁剪掉。
2. 最终总编辑的 JSON 或 claim 校验失败后，系统会进入 deterministic fallback；
   旧 fallback 直接拼接 evidence 摘要，导致正文出现“同簇标题”“摘要信息”
   和结构化 evidence 标题等调试痕迹。
3. 质量门对赛前/赛程文章过于敏感，可能把场外赛程讨论误判成“未开赛写成已完赛”，
   迫使一篇本可修复的模型稿降级。

## 决策

1. 日报证据预算上调：标准日报应优先覆盖全天热门比赛、转会、教练、人物和场外议题，
   而不是沿用 Beta 阶段的小样本设置。
2. 质量门继续拦截“未开赛写成已完赛”，但只在 match report 或明确结果 claim 中触发；
   场外/赛程栏目可以讨论开球时间、旅行安排和组织争议。
3. 未在来源中精确定位的引号内容自动降级为转述，并记录 warning；仍不允许伪造直接引语。
4. deterministic fallback 必须生成读者安全稿：可保守、可短，但不得暴露内部 evidence
   标记、story cluster 调试信息或“摘要信息”模板。
5. 后续搜索能力采用 gap-driven search：Leader 或栏目小组输出缺口清单，系统调用
   Source Registry 登记的搜索 API/RSS/MCP 连接器补证据，再回到精简和写作层。
   不把 LLM 对话历史、未登记网页或任意浏览结果当作业务事实库。

## 后果

- 模型合稿更不容易因为非核心安全误判降级。
- 即使降级，用户看到的也是可读的保守稿，而不是调试稿。
- “鼓励模型需要信息时上网搜索”被落为受治理的产品流程：模型提出缺口，
  系统负责用批准来源搜索和校验。

## 验证

- 单元测试覆盖场外赛程文章不再被误判为已完赛战报。
- 单元测试覆盖 unsupported quote 自动转述。
- 单元测试覆盖 deterministic fallback 不输出“同簇标题”“摘要信息”和结构化 evidence 标记。
