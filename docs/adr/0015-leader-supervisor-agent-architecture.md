# ADR 0015：Leader 监督层与多 Agent 交接合同

- 状态：Accepted
- 日期：2026-07-03

## 背景

真实测试中出现普通世界杯日报只剩若塔相关材料的情况。根因不是若塔单点事实，而是 Agent 系统缺少一个总领全局的交接审查者：资料层取得了关键人物护栏证据后，下游可能把护栏当成主线，资料精简层也可能在压缩时丢掉原始主题信号。

用户期望的形态类似成熟 Agent 产品：多个模型/席位分工合作、互相交接、反思检查，但不能变成无限对话或无边界自治。

## 决策

在 URL 收集、资料精简和增强层之后，新增 `leader_review` 阶段。Leader/Supervisor 不写报道、不新增来源、不替专家席研究，只检查写作合同是否健康：

- 主题覆盖是否仍然匹配用户请求。
- 关键人物护栏是否挤占普通日报主线。
- 证据是否覆盖赛事、转会、场外、背景等栏目。
- 增强层是否交付可用媒体资产。
- 上游是否降级，以及是否需要人工回退。

普通主题如果只剩关键人物相关材料，Leader 必须阻断生成，避免交付偏题日报。若主题本身就是关键人物，官方关键状态证据可以作为最小可交付包。

当前实现采用确定性 Leader，以降低不稳定性；后续可以替换为 Minimax、长上下文模型或更强规划模型，但必须保持同一结构化输出：`decision`、`critical_subject_mode`、`topical_evidence`、`critical_related`、`coverage`、`media_assets`、`repair_attempts` 和 `human_fallback`。

2026-07-03 的 ADR 0016 将该层升级为“先分栏、再监督”：重大人物状态不再自动注入普通日报 evidence，而是作为事实护栏参与校验；Leader 输出栏目计划和负责小组。

## 后果

- 关键人物事实护栏继续保护正文，不再在普通日报中抢占主线排序。
- 每个资料层和 Leader 都会进入 Harness Trace，方便查看哪一层交付不足。
- 预测、日报和转会报告的 Skill runtime 均加入 `leader_review`，版本同步升级。
- 这不是开放式多 Agent 聊天；Leader 只有一次有界检查和最多一次未来可扩展的修复机会。

## 验证

- 测试覆盖普通日报中关键人物护栏不会压过 Portugal/Croatia 主题证据。
- 测试覆盖普通日报只剩若塔相关材料时，Leader 阻断生成。
- 测试覆盖 `layer_runs` 包含 `leader_review` 且每层都有 checkpoint。
- 继续保留关键人物主题的官方兜底路径。
