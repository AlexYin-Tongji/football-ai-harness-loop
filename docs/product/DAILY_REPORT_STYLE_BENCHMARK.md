# 《今日球脉》日报写法基准

- 状态：Draft
- 日期：2026-07-04

## 参考观察

公开足球日报和战报常见结构可以分成两类：

1. 战报型：先交代北京时间、赛事、场地、对阵和最终比分；随后按“关键事件”列出进球、VAR、点球、红牌、比分变化和晋级影响。懂球帝战报页通常采用这种信息密度高的结构，适合赛场主线。
2. Daily briefing 型：先给当天最重要的主线，再把比赛、转会、场外和背景串成一篇有判断的日报。Guardian Football Daily/Football 频道更接近这种“主线 + 语境 + 补充线索”的组织方式。

这些参考只用于产品结构和信息组织，不复制原文表达，也不把未授权页面正文存入系统。

## 球脉目标版式

1. **开场 30 秒**：用 3-5 句讲“今天真正变化了什么”，并明确哪些是确认事实、哪些是报道线索。
2. **赛场主线**：每场比赛独立成段。段落顺序为：北京时间/赛事/场地 -> 对阵/比分 -> 关键事件时间线 -> 晋级或下一轮影响 -> 画面目标。
3. **关键事件**：优先结构化呈现分钟、球员、动作、比分变化、VAR/点球/红牌；证据没有分钟时写“分钟未见可靠来源”，不得补造。
4. **转会市场**：每个重要转会独立成段，写清球员、当前球队、目标球队、阶段、金额/合同/体检证据和未知项。
5. **人物/教练补充**：只在能帮助理解主线时出现。位置、履历、成绩、赛季数据必须来自证据或授权结构化来源。
6. **图片与视频**：战报段优先官方高光缩略图或许可图片；人物段优先 Commons 许可图片。没有自动许可素材时生成明确人工补图目标。
7. **来源边界**：正文自然写出来源名和不确定性，来源链接由 UI 列表和 evidence tag 承担，不把文章写成审计清单。

## 质量门映射

- 每个二级标题至少绑定一个 `evidence_id`。
- 每个带数字的 claim 必须能在引用证据中找到同一数字。
- `unverified_lead` 相关 claim 必须逐句保留“传闻/据报道/未核实/线索”标签。
- 战报栏目若存在多场比赛，必须拆成多个二级标题。
- 转会栏目若存在多条转会，必须拆成多个二级标题。
- 媒体资产必须绑定目标 evidence，并按 `report_cover`、`section`、`timeline` 或 `spotlight` 放置。
